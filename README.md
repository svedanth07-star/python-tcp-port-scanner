# Python TCP Port Scanner

A multithreaded TCP port scanner written in Python.

## Features

- TCP port scanning
- Hostname and IP address support
- Port range validation
- Multithreaded scanning
- Service detection
- HTTP banner grabbing
- Configurable timeout
- Scan time measurement
- Results saved to a text file
- Command-line arguments
- Error logging

## Requirements

- Python 3
- Linux / Kali Linux 

## Usage

```bash
python3 scanner.py <target> <start_port> <end_port>
